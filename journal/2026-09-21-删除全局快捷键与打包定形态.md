## 一、删除全局快捷键（ADR 032）

用户原话：**"把快捷键功能删除吧，不需要快捷键了。单击托盘就可以隐藏显示。"**

### 先核实用户的前提

他说"单击托盘就可以隐藏显示" —— 我去 `src/host/tray.ts` 确认：
`tray.on('click', () => { (opts.onClick ?? opts.actions.toggleVisibility)(); })`。
**本来就是现状**，不需要新写代码。前提成立，删掉快捷键不减少任何能力。

（这一步值得做：如果托盘单击原本不是 toggle，我删完就等于把用户唯一一个快捷入口也删了。）

### 为什么是"删除"而不是"保留但默认关"

四条独立成立的理由，都写进了 ADR 032：
1. 注册→归一化→唤出这条路径**从未被真实走过一次**；
2. 它是**静默失败面**（`Win` 必须写成 `Super`，直接注册返回 true 但永不触发，ADR 012）；
3. 它是「被误判为流氓软件」风险表的一项；
4. 替代路径本来就有。

### 删了什么

`src/host/hotkey.ts` 整个模块 / `prefs.hotkey` / `PetMenuView.hotkey` + 菜单只读行 /

`interaction.hideShortcut` 置 **`null`** 并附注记 —— 保留"这里曾经有过一个开关、默认值是什么"，
将来要加回时看得见。抹掉历史比留个 null 更糟。

### 踩的两个坑

   表现为 `status-arbiter.test.mjs` 在 `require(desktop-pet.json)` 处炸掉。
   教训：**改完 JSON 立刻 `JSON.parse` 校验一次**，别等测试报错才回头。
2. **Edit 工具这轮不太可靠**：三次"Successfully edited"但文件没变（另两次报 EBUSY）。
   改用一次性 node 脚本做替换才落盘。**这类"报告成功但没生效"最危险** —— 差点让我以为改完了。
   收工前我对关键文件逐一 grep 复核过。

### 探针必须改，但命题没变

`spikes/m2-control/probe-key-path.js` 原来用 `pressHotkey()`（注入 Win+Alt+P）做"收起→再唤出"往返。
改成**右键宠物**（本来就是 toggle）。这个探针要验的是 ADR 009 那个坑在**键盘路径**上是否复现
（hide→show 往返后键盘还进不进得来）—— 换哪条路径都不影响结论。
**结果：往返后键盘增量仍 = 1**，证明这条结论没被删除破坏。

## 二、打包形态定为免安装绿色目录（#13）

给用户的选择摆了实测数字：Electron 运行时 **368 MB**、`electron.exe` 是 **GUI 子系统（PE subsystem = 2）**、
koffi 的 `.node` 在 `@koromix/koffi-win32-x64`（**不能从 asar 内加载**）、npm 10.9.7 可用、
打包工具链一个都没装。

用户选：**免安装绿色目录**。

**GUI 子系统这条值得一记**：ADR 028/029 折腾两轮的"关窗宠物消失"根因是**继承了启动者的控制台**，
不是 Electron 自己开控制台。打包后由 explorer 双击启动就没有父控制台 —— 所以 #13 确实是正解。
