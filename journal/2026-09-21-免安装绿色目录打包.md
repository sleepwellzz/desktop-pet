# 2026-09-21（第三轮）· 免安装绿色目录打包产出（ADR 033）

## 做了什么

继上两轮（判据 9 收口、删除快捷键）之后做 #13 打包。形态由用户在四个选项中定为**免安装绿色目录**。

`node tools/make-portable.mjs` ⇒ `dist-win/desktop-pet/`，**373 MB**，零新依赖、零联网下载。

## 选型前先量了四个数（都是实测，不是印象）

| 数 | 对选型的影响 |
|---|---|
| Electron 运行时 **368 MB**（73 文件） | 两种形态都是 370MB 量级，安装器不会让它变小 |
| `electron.exe` 的 **PE 子系统 = 2（GUI）** | 它从不自建控制台 ⇒ ADR 028/029 折腾两轮的根因是**继承启动者的控制台**，不是 Electron 自己开控制台。打包后由资源管理器双击就没有父控制台 —— #13 是正解这一判断**成立** |
| koffi 的 `.node` 在 `@koromix/koffi-win32-x64` | **`.node` 不能从 asar 内加载** ⇒ 目录形态天然绕开，不必配 `asarUnpack` |
| 打包器**一个没装**，npm 10.9.7 可用 | 装 builder 要新增依赖 + 首次构建联网下载 nsis/winCodeSign |

**顺带更正一条记忆**：项目记忆里写着"Bash 没有 npm"，实测 `npm.cmd --version` = **10.9.7**，可用。
（那条记忆当初可能是 Bash shim 拦了裸 `npm` 造成的。）以后要装依赖可以直接装。

## 布局

```
dist-win/desktop-pet/
├── desktop-pet.exe      ← electron.exe 改名（ASCII 名，避开 ADR 029 那类路径问题）
├── Electron 运行时文件（368 MB）
└── resources/app/       ← 应用本体，目录形态，故意不打 asar
    ├── dist/ assets/ package.json pet.json spritesheet.webp desktop-pet.json behavior-map.json
    └── node_modules/    ← 只带 koffi + @koromix（不带整个 node_modules）
```

`resolvePackDir()` 是 `resolve(__dirname,'..','..')`，`__dirname` = `dist/main`，
上两级正好是应用根 ⇒ 打包后就是 `resources/app`。**这条是实测确认的，不是推断。**

Electron 认 `resources/app/` ✅｜koffi 无报错 ✅｜托盘图标随包分发 ✅｜全链路正常 ✅｜`isPackaged=true` ✅。

为拿最后一条，给 `boot()` 加了一行打包态日志。
**动机**：`app.isPackaged` 决定开机自启写进注册表的命令形态（未打包要带应用路径参数、已打包不能带），
**只能实测不能猜** —— 猜错就是写错注册表。

## 本轮踩的坑

1. **`desktop-pet.json` 里写进未转义的 ASCII 引号** → JSON 失效，测试在 `require(json)` 处炸。
   教训：**改完 JSON 立刻 `JSON.parse` 校验**。
2. **Edit 工具这轮不可靠**：多次"Successfully edited"但文件没变（另几次报 EBUSY），
   还有一次是替换串里带反引号被 bash 吃掉。改用一次性 node 脚本才落盘。
   **"报告成功但没生效"最危险** —— 让我差点以为改完了。收工前对关键文件逐一 grep 复核过。
3. **ESM 脚本里混用 `require` 与 `await import`** → `ERR_AMBIGUOUS_MODULE_SYNTAX`。
   修的时候又漏删重复声明，报了第二次错。小脚本也该一次写完再跑。

## #13 两项复核的程度（如实）

- **托盘图标随包分发** ✅ 已复核（日志显示从包内 `assets/tray.ico` 读出并创建成功）。
- **注册表值名** ⚠️ **只复核了一半**：`isPackaged=true` 已实测 ⇒ 走 `{ path: execPath, args: [] }`
  的正确分支（不会再出现开发态那种 `electron.exe <应用目录>`）；值名应为 `desktop-pet`
  （开发态是 `electron.app.Electron`）。但 **`reg.exe` 被沙箱策略拦截**，字面值没读到 ——
  **不去绕**（明确要求），留给用户勾一次「开机自启」时确认，非阻塞。
