## 过程中修掉的四个真缺陷（详见 ADR 011 负面结论）

1. **`pointermove` 的 `e.button` 是 −1**：给拖动加"只处理左键"判断时连 `pointermove` 一起判了，
   整段拖动**静默失效**。症状极有欺骗性：`down=1 up=1 move=10` 计数全正常，窗口一动不动。
2. **命中判定只跟光标不跟动画**：点一下宠物（切到挥手姿态）后不移动鼠标直接拖动 → 光标下的像素
   已变空白 → 窗口被切成穿透 → 按下直接穿透。改为渲染层**每帧复评**。
3. **桌面被误判成全屏应用**：点任务栏"显示桌面"条后前台变成 `WorkerW`（2560×1600、空标题、
   可见、未最小化），`GetShellWindow()`/`GetDesktopWindow()` 都拦不住它 → `coversMonitor=true`
   → 宠物自我隐藏。用户视角是"点一下桌面，宠物不见了"。按窗口类名排除桌面/任务栏一族。
4. **`GetClassNameW` 返回值差一错误**：按 `(len−1)*2` 截断把 `WorkerW` 读成 `Worker`，
   白名单恒不匹配 —— 让 ③ 的修复**静默失效过一轮**。现在探针会把 `fgClass` 打印出来。

顺带记一条探针经验：**菜单在屏幕边缘会整体翻折**（宠物在右下角时菜单跑到光标右上方），
按直觉猜点击偏移必然全错 —— 第一版 5 个候选点全部落空，靠全屏截图量几何才点中。

## 人工验收（观感，机器查不了的部分）

机器已验：菜单可点、隐藏显示往返后仍可点可拖、缩放尺寸与命中、自启注册表、退出进程消失。
**留给人看的**：菜单长什么样、点起来顺不顺、缩放观感、托盘图标在任务栏上是否看得清。

1. 双击 `启动桌宠.bat`（那个窗口别关，它是桌宠本体兼日志窗口）。等宠物出现在右下角。
2. **看托盘**：任务栏通知区域应出现一枚圆形徽章图标（狗头 + 暖棕底）。
   左键单击它 → 宠物收起；再单击 → 宠物回来且**仍可拖动**。
3. **右键托盘图标** → 菜单应包含：状态行（如"状态：空闲"）、隐藏宠物、宠物大小（子菜单）、
   重置大小、开机自启（勾选框）、退出。逐项点一遍：
   - 宠物大小 → 1.0：宠物**原地变大**（脚不离地），窗口不会跑到屏幕外；
   - 重置大小：回到默认大小；
   - 开机自启：勾上后**再打开菜单应仍是勾选态**（回读），之后请**取消勾选**（避免真开机自启）；
   - 隐藏宠物 / 显示宠物。
4. **在宠物身上右键** → 应弹出同一套菜单；选"隐藏宠物"，再从托盘把宠物叫回来，
   确认**还能点击和拖动**（这是 ADR 009 那条通路）。
5. **退出**：菜单里点"退出" → 宠物消失、托盘图标消失、`启动桌宠.bat` 的窗口回到提示符（进程真的退了）。

判据：任何一项点了没反应、或菜单里出现空白/错位的项，都要报给我。
