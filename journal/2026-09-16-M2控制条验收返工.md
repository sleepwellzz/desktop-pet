# 2026-09-16 · M2 ④ 人工验收返工

用户验收 M2 ④ 后报 6 条，全部处理完、回归全绿。处理与证据见 ADR 014 的"验收返工"节，要点：

- **最重的发现：`hitAt` 命中换算缺少边界检查（M1 起就存在的 bug）。** 窗口外负坐标经
  `column*cw + localX` 整数运算落回图集**其它行列**、命中别的精灵 → 判定随动画帧抖动 →
  ① 远处鼠标触发控制条；② 悬停 hideAt 被无限重置、面板收不掉。
  日志证据：同一个 css=(-553,-813) 时而"空白"时而"实体"；探针采样显示 hideAt 每 200ms 被刷新
  （167→323→109→null→184→…）。修法：hitAt 加客户区 + 单元格两层边界检查。
  修后采样：400ms 起稳定收起、渲染层命中恒 false、旧矩形位置不再唤出面板。
  **教训：边界 bug 只在坐标极端时显形，探针采样必须覆盖远离目标的点。**
- 其余修复：面板隐藏后旧矩形不再参与悬停判定（`isVisible() ? bounds() : null`）；
  × 按钮缺 data-cmd（事件委托机制下点击完全无效，已补）；「确认」被 500ms 限流挡住
  （ack 现在立即生效，且限流本身未废——单测双向钉住）。
- 按用户意见调整：撤掉 −/+/↺（缩放走"⋯ 更多"里的那份菜单，`BarCommandId` 缩到 4 个）；
  hoverGraceMs 500→350。
- 残留会话（default · manual-acceptance 一直显示"运行中"）：**不是链路故障**。隔离验证证明
  状态可连续覆盖（idle→running→blocked→needs-input→idle 全过）；事件流水证明用户每次喂都被
  记录。真相：状态文件是快照、上次验收的会话原样残留；用户按 8/9 操作的是**会话 b**，
  default 那行当然不变。产品层补「清空状态会话（N 条）」菜单项 + 会话行"已静默"标注。
- 回归：单测 **131**、m2-control PASS（幽灵区域 + × 新用例）、命中图**误吃 0**（169 点、
  用户实际缩放 0.75 环境）、全屏两轮 PASS、托盘 PASS。

## 给下一个会话的验收提示（用户复验清单）

1. 光标移到屏幕远处（四个角落都试）→ 面板**绝不该**出现；悬停出现后移开 → 应明显更快消失（350ms）；
2. 点面板右上角 × → 立即收起（不再只有 Esc 能关）；
3. 点会话行的「确认」→ 宠物与面板**立即**变化（不再等半秒）；
4. 一启动若又见到残留会话：右键宠物或托盘 →「清空状态会话」一键清掉；面板里很久没动静的
   会话行时间会变成暖色，悬停有解释。
