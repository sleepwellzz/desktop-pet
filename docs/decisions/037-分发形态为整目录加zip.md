# ADR 037：分发单位是「整个目录」，对外压成一个 zip；`desktop-pet.exe` 不能单独发

- 日期：2026-09-22
- 触发：用户问「这个 EXE 只要发这一个文件给别人，别人就可以使用，对吧？」
- 结论：**不对。** exe 只是入口，必须整目录分发；对外给一个 zip（153 MB）

---

## 1. 用户的问题与正确答案

> 「这个 EXE 只要发这一个文件给别人，别人就可以使用，对吧？不需要把其他文件也发给他，
>  也就是说这个单一的文件就是我们的 Portable 软件，对吗？」

**答案是否定的。** 这是本轮最需要纠正的一条认知。

我们的便携版 = **一个 373 MB、232 个文件的目录**：

```
desktop-pet/                       ← 这一整个目录才是"软件"
├── desktop-pet.exe                ← 只是**入口**
├── resources/                     ← 应用本体（app/）+ Electron 资源
├── *.dll  icudtl.dat  *.pak       ← Electron 运行时，缺一不可
├── locales/                       ← 55 个语言包
└── README.txt
```

`desktop-pet.exe` 启动时会在**同级目录**里找 `resources/`、`*.dll`、`*.pak`、`locales/`。
只把 exe 单独发出去，对方双击的症状是 **毫无反应、也没有任何报错** ——
这个症状本项目**实测踩到过**（本轮做 rcedit 实验时，把 exe 单独拷到别处跑，
表现就是"什么都没发生"，排查花了两轮）。

**所以"发送一个文件"这件事本身是能做的，但载体不是 exe，是 zip。**

## 2. 分发形态：`npm run make:portable:zip`

打包脚本加了 `--zip`：在 `dist-win/` 下产出

```
dist-win/desktop-pet-win-x64.zip     153 MB   ← 发给别人的那**一个**文件
```

- 用系统自带的 **bsdtar**（`tar -a -c -f x.zip`，Win10 1803+）而不是 PowerShell 的
  `Compress-Archive`：快得多。
- 从 `dist-win/` 里压缩，解出来的第一层就是 `desktop-pet/` 目录 —— 对方不会解出一地散文件。
- 体积：373 MB → **153 MB**（Electron 的 dll/pak 本身已压缩，所以压缩率不高，属正常）。

## 3. 实测：模拟"别人拿到 zip"

不能只验证"压出来了"。所以做了端到端的一次：

| 步骤 | 结果 |
|---|---|
| 解压到**全新目录** | ✅ status=0，exe 就位 |
| 启动 | ✅ 进程存活 |
| 日志（按启动时间戳锚定） | ✅ 留下一条"10 秒前"的启动记录，窗口已显示、精灵图就绪、状态通道正常 |
| 未捕获异常 / 错误 | ✅ **无** |
| 清理 | ✅ 临时目录已删 |

⇒ **"发一个 zip 给对方、对方解压即用"这件事已成立。**

## 4. 顺手修掉的一个真缺陷：zip 里的非 ASCII 文件名会坏

第一版 zip 里那个给用户看的说明文件叫 `说明.txt`。用 `tar -tf` 列回来时它的名字已经变成
`?��.txt` —— 码点是 `U+FFFD`（替换字符），即**文件名在 zip 里就已经损坏**。
bsdtar 在 Windows 上写 zip 时对非 ASCII 文件名的编码处理不可靠。

⇒ 改名 **`README.txt`**（内容仍是中文，只是**文件名**一律 ASCII）。
现在 zip 内 262 个条目**无一含非 ASCII 名**。

这条与项目里既有的两条同源，都归到"Windows 上跟编码打交道一律保守"：
`.bat` 必须纯 ASCII、写进 exe 版本资源的值必须 ASCII、**进 zip 的文件名必须 ASCII**。

## 5. 给别人用的时候，还有三件事要提前说

1. **未签名的 exe 首次运行会被 SmartScreen 拦**（"Windows 已保护你的电脑"）。
   对方需要点"更多信息 → 仍要运行"。这是没买代码签名证书的必然代价，不是 bug。
2. **解压路径别太深、别含奇怪字符**。工程路径含空格是没问题的（本项目自己就在含空格路径下跑），
   但把 370 MB 解到中文+空格很深的目录里没必要冒险。
3. **勾了开机自启之后不要移动目录** —— 注册表 `HKCU\...\Run` 里记的是绝对路径，
   移动后会指向不存在的文件；需要在新位置重新双击一次让它自己修正。
   （这条已写进 `README.txt`。）

## 6. 如果将来真想要"单个 exe 双击即用"

技术上可行，但要引入自解压外壳（7-Zip SFX / IExpress / NSIS），
**本质仍是"先解压到一个临时目录再运行"** —— Electron 应用做不到真正的单文件，
因为 368 MB 的运行时必须以文件形式落在磁盘上。
⇒ 收益（少一步解压）小于代价（新工具链 + 首次启动变慢 + 临时目录残留），**本轮不做**。
