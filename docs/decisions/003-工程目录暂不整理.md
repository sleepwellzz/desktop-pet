# 003 · 工程根目录暂不整理

- **状态**：已接受
- **日期**：2026-09-15

## 背景

曾考虑把根目录的文档与数据契约整理进 `docs/`、`data/` 等分区目录，使结构更整洁。

## 核实到的事实

根目录文件之间已形成相对引用网，整理会破坏当前可工作的工具：

| 文件 | 依赖（同目录相对路径） |
|---|---|
| `动画映射验证器.html` | `spritesheet.webp`（CSS `background-image`） |
| `Windows桌面宠物开发方案.html` | `atlas-map.png`（`<img src>`） |
| `desktop-pet.json` | `pet.json`、`behavior-map.json`、`spritesheet.webp` |
| `behavior-map.json` | `pet.json`、`spritesheet.webp` |

## 决策

**保持根目录现有文件不动**，只做增量新增（`docs/`、`journal/`、`spikes/`、`src/`）。整理推迟到 M1 建立正式代码结构时统一进行，届时同步更新所有引用。

## 理由

稳定优先于整洁。当前验证器与文档均可正常工作，为一个非功能性目标去动引用链，风险与收益不成比例。M1 写代码时本来就要重新组织资产加载路径，那时一并整理成本最低。

## 后果

- 根目录文件数量偏多（约 12 项），短期内接受。
- 新增内容一律进分区目录，不再往根目录堆。
- M1 启动时必须重新评估本决策。
