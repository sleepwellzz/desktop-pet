## 5. 本轮踩的坑（都是"判据不纯"，值得下一个会话知道）

同一个错误在一轮里出现了**三次变体**，每次都让"看起来通过的验证"失效：

| # | 我测的 | 我要证的 | 结果 |
|---|---|---|---|
| 1 | 启动 electron 时 conhost 数量不变 | 它没附加到 cmd 已有的控制台 | ✗ 用户实测打脸："关窗宠物消失" |
| 2 | `AttachConsole(pid)` 判断有无控制台 | 同上 | ✗ 忘了先 `FreeConsole()`，它对每个进程都失败 |
| 3 | 用**不含空格**的临时路径测启动方式 | 真实工程路径（**含空格**）能用 | ✗ 用户双击报 `Unable to find Electron app at <工程目录>` |

**共同点：判据与命题之间隔了一层我自己的假设。**
落笔前的自检问题：**这个数字/这个输入，能直接支持我要下的结论吗？**
（已写进 `docs/constraints/build-probe.md`，与"探针两次输入之间必须推进时钟"并列。）

**另一条教训**：`.bat` 里**只加中文注释**也会让脚本 exit 1（cmd 按 GBK 解析注释）。
改任何 `.bat` 都要脚本校验非 ASCII 字节数 == 0 —— 这条也已在约束里。

## 6. 环境事实（接续必读，省得重新踩）

- Bash shim **缺 `head`/`tail`/`ls`/`dirname`/`cat`**，`rm`/`grep` 会被拦 → 用 Read/Write/Edit/Glob/Grep；
  跑脚本用绝对路径 node 22.22.2-3。**没有 npm** → `node tools/npm-run.mjs build`。
- PowerShell 工具**不回传 stdout** → spawnSync 捕获，或写文件再 Read。
- **`wmic` 被沙箱策略阻止**（不可绕过）→ 要进程信息用 `tasklist` / Python `ctypes`。
- **沙箱在命令结束时清理整个进程树** → 我启动的 Electron 留不住，"长期驻留"这类验证只能由用户做。
- **宿主 WorkBuddy 的进程名是 `WorkBuddy.exe`**（14 个），所以 `electron.exe` 全都是桌宠
  —— 但**仍然不要按镜像名杀**，按 PID 杀自己那条树。
- 工程路径**含空格** → 传路径参数给 PowerShell 要小心（见 §5 第 3 条）。
- 用户机器上**同时只能跑一个宠物实例**：我跑真实窗口探针时要挑用户没在用宠物的时段。
