## 二、本轮做完了什么

用户的目标：**工程「非常完备且具有可塑性」** + **换宠物要流畅**，并要求先做完备（收口 P0）。

### ① 换宠物成为正式目标（ADR 049）

**先说清一件事**：换宠物被关闭过两次（ADR 015 搁置、ADR 046「不打算做成可换宠物的平台」）。
本轮**走新 ADR 取代 ADR 046 的后半句**（前半句「对外定位是叫淘淘的软件」保留）。
**理由**：ADR 046 回答的是"对外定位"，而用户问的是"工程能不能长出我没想到的东西"——
**可塑性服务的是维护者，不是访客**。

**核实先于动手**，结论是**基础已经很齐**，成本不在功能而在规范与判据：

| 能力 | 现状 |
|---|---|
| `loadPack(packDir)` | ✅ 已接受目录参数 |
| `--pet=<目录>` 启动参数 | ✅ 已存在（`index.ts:59`） |
| 网格规格 | ✅ 由 `spriteVersionNumber` 推导 |
| 状态 → 行号 | ✅ 全走 `behavior-map.json`，**代码零硬编码行号** |
| 路径穿越防护 / 契约校验器 | ✅ 都在 |

**全仓只查出一处真绑死，已修**：托盘图标写死工程根 `assets/tray.ico`，
而 `make-tray-icon.py` 开头就写着「换一只宠物包就该换一次图标」——**两边矛盾**，
换包后托盘还是旧的脸**且无任何报错**。现在改为**包内 `tray.ico` 优先**。

**新增**：
- `tools/check-pet-swap.mjs`：**不启动 Electron** 体检任意宠物包，
  堵 `loadPack` **只 warn 就放过**的四个洞（见下）
- `docs/pet-pack-guide.md`：可执行的制作路径（最短 7 步 / 行语义 / 三份配置咬合 / 八条坑）
- `make-tray-icon.py` 支持 `python tools/make-tray-icon.py <包目录>`

**`check-pet-swap` 堵的是什么**（`loadPack` 会静默放过的）：

| 洞 | 后果 |
|---|---|
| `pack.ts:87` 对"behavior-map 有、runtime 没有"的状态只 `warnings.push` 后跳过 | **宠物静默少一个动作** |
| 只强制要求 `idle`，而 5 业务状态 + 9 面板动作靠 `statusMap`/`actions` 指过去 | 该状态永不出现，**无报错** |
| `statusMap` 指向不存在的动画 | agent 进入时无动作可演 |
| 锚点不自洽 | 脚离地 |

> ⚠️ **`check-pet-swap` 体检工程根自己**，并接进主单测 ⓪d。
> 理由：**自己过不了的判据没资格要求别人过。**

### ② 构建链的三处静默失真（ADR 050，审计 P0-2/3/4/8）

四条**同一种病**：*构建链会产出"看起来成功"的东西，而它其实是坏的。*

| 编号 | 原来的病 | 现在 |
|---|---|---|
| P0-2 | `build` **完全不跑** preload 类型检查 ⇒ 通道名拼错只在运行时表现为"按钮没反应" | `prebuild` 钩子 + `run-build.cjs` 最前面两步 noEmit |
| P0-3 | `tsconfig.json` 的 `include` **覆盖 `src/renderer`** ⇒ tsc 把 renderer 编成 **CommonJS** 同名覆盖 esbuild 的 **IIFE** ⇒ **白屏** | renderer 从 `exclude` 掉 + `tsconfig.renderer.json`；`watch` 重写为 `tools/watch.mjs` |
| P0-4 | 打包只判 `dist/main/index.js` **存在** ⇒ 改完 `src` 直接打包会产出"**1.0.2 版装着 1.0.1 代码**"且四处自洽 | 调 `verifyDist()` 比 **`src/` 内容哈希** |
| P0-8 | `acceptance.md` 硬写版本号 ⇒ 照单验收**必然假判红** | 改 `<版本号>` + 断言扫版本串与 `package.json` 比对 |

> **P0-3 是实测复现的，不是照抄报告**：正式 build 一直靠"tsc 先跑、esbuild 后跑"的
> **顺序侥幸掩盖**，写 `watch` 时暴露。
>
> **`exclude` 写目录而不是逐个文件** —— 将来新增 renderer 源文件时**没人会记得**改 exclude。

**主单测 452 → 457 项。**

### 2. 一次验证失误（教训已写进 AGENTS 口径）

验证 `watch` 时我先往 `preload.ts` 追了一行**注释**再查产物 —— 结论"没生效"是**错的**：
**esbuild 会剥离注释**。换成真实代码改动后立刻验证成功。

顺带暴露一个操作习惯问题：那条命令写成 `grep -c … && cp 还原`，
而 `grep -c` 无匹配返回 0 ⇒ **`&&` 链中断，源文件没被还原**，第二次检查才发现。

⇒ **验证要用会出现在产物里的东西**；**"检查 + 还原"不能串在 `&&` 链里**。

- **别删 `spikes/` 里的产物**，也别把 `spikes/**/*.json` / `*.out` / `*.log` 加进 `.gitignore` ——

- **别搬根目录的文件** —— ADR 003 的引用网仍然成立。见 `PLAN.md` §5。

- **别单独用 `tsc --watch`** —— 它会把 renderer 覆盖成 CommonJS ⇒ 白屏。用 `npm run watch`。
- **想验证有顶层副作用的脚本能否解析，用 `node --check`，不要 `import` 它**
  （`spikes/*/run.mjs` 顶层就 spawn electron；2026-09-28 因此误跑过一次 GUI 探针）。
- **验证要用会出现在产物里的东西**（注释会被 esbuild 剥离）。
