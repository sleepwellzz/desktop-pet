**人工验收怎么做**（每轮里程碑结束时走一遍，步骤与期望写在
`journal/2026-09-16-状态源接入.md` 的"人工验收"一节）：启动桌宠 → 双击 `喂状态.bat` →
按 1..9 逐个喂状态 → 对照期望动作与日志。重点看**粘滞**（喂 needs-input 后再喂 running，
宠物必须保持等待）、一次性动作的**落点**（ready 要挥手后落到 review，不是回待机）、
**`+1` 角标**（按 4 再按 8：气泡右侧出现 `+1`；按 9 消失），以及**气泡文字**（左右居中等宽余量、
字的下缘不缺笔画）。

**M2 ④ 控制条要额外测这几条**（探针覆盖不了的只有"好不好用"；探针能覆盖的见 `spikes/m2-control/README.md`。
**2026-09-17 按新交互模型（ADR 016）重写**：旧清单里的"悬停出现"已删除、`+`/`↺` 按钮上一轮就撤掉了）：
1. **光标停在宠物上 2 秒 → 面板绝不出现**（悬停已彻底移除）。顺手确认在别的窗口打字不受影响；
2. **右键宠物 → 面板出现并抢到焦点**（能按 Esc 收起）；**再右键一次 → 收起**；
   光标仍停在宠物上，**不应该自己弹回来**；
3. 托盘右键 → 仍是**那份完整菜单**（与宠物右键不是一回事）：隐藏/显示、宠物大小、重置大小、
   清空状态会话、开机自启、退出都能点；
4. ~~按 `Win+Alt+P` → 面板出现/收起~~ —— **该项随全局快捷键一并删除（ADR 032，2026-09-21）**。
   替代口径：宠物**隐藏后**用**托盘左键单击**叫回来（这是隐藏后唯一的快捷入口）；
5. 面板上的会话行：喂两条会话（按 4 再按 8）→ 面板列出两行；点「确认」→ 该行按钮消失，
   宠物不再举着手；
6. 动作排：`隐藏宠物`（面板应跟着消失）/ 中间显示的是**宠物名**（不是百分比）/ `⋯` 弹出与托盘
   同一份菜单 —— 点完「⋯」菜单弹出的瞬间**面板不能消失**（消失了菜单会跟着没）；
7. 把宠物**拖到屏幕最底部** → 面板应翻到宠物**上方**，且不盖住气泡；
8. 菜单里的「清空状态会话」→ 面板当场**一行不剩**、菜单项变灰（这一条上一轮是坏的，ADR 017）；
9. 左键单击宠物 → 播一次「双手拜一下」；**不该冒出任何面板**。

**M3 第三块的人工复验清单（2026-09-18，ADR 021；上一轮由用户提出的两条问题）**：
1. **不让任何 agent 跑，重启桌宠 → 宠物应停在默认待机（第 0 行）**，
   不该再一启动就炒菜（这条是本轮主要修复目标）；
2. **真发一条消息给 agent → 宠物应进第 7 行（生日姿态）；agent 干完 → 60 秒内退场回待机**，
   不再永久炒菜（`ready` 的落点是第 8 行小厨师，通报期内能看到）；
3. **气泡应贴在宠物正上方**，不该再出现在屏幕正中；
4. **要授权时（`needs-input`）→ 气泡常驻 + 宠物举手**；**点「确认」或单击宠物** → 收回；
5. **受阻（`blocked`）时气泡应常驻**（与打盹同样画第 5 行趴卧，靠气泡区分）；
6. **想验"代理干完活"这层语义**：在控制条上「⋯」/ 托盘菜单里点「清空状态会话」，
   宠物应立刻回到待机。

**手动把玩（控制条动作排）的人工复验清单（2026-09-22，ADR 038）**：
探针覆盖了"机制对不对"（`spikes/m2-control` 用例 ⑫b），这里只列**探针测不了的观感**：
1. **右键宠物 → 面板第 3 段应该是 9 个动作按钮**（待机 / 左走 / 右走 / 拜一拜 / 跳一下 /
   趴下 / 等一等 / 过生日 / 炒菜），两行铺满。**先看按钮文字会不会被裁掉**（宽 260px / 5 列）；
2. **不启动任何 agent，逐个点一遍**：每个都该演起来；被点的那个**暖色高亮**；
   **6 秒内自动回到待机**（不用你做什么）。过生日与小厨师认不认得出、够不够好玩 —— 这是主观项；
3. **点「左走」→ 它应该真的往左走一段**（不是原地踏步）。**面板会先消失、走完自己回来**；
   回来后面板应重新贴着宠物**居中**、且**还能继续点**（别只看着回来了就放心）。
   —— "面板跟着飘"那个观感用户已明确不要（ADR 039），所以这一条现在是**期望**行为；
   （机制与边界已在探针 ⑫c 里覆盖，这里只确认观感。）
4. **点一下，再点同一个按钮 → 立刻停**；点不同的按钮 → 换过去（不用先停）；
5. **正在演的时候，等它自己结束 → 按钮的高亮应该消失**；
   （这一条是本轮修掉的那个缺陷：曾经会**一直亮着**。若又看到亮着不动，请告诉我。）
6. **点完之后看宠物上方 —— 不该出现任何气泡文字**。气泡只该由 agent 状态触发；
7. **贴着屏幕左边缘点「左走」**（先把它拖到最左边）→ 应该**原地演一遍**而不是假装走了，
   也不该把窗口顶出屏幕；
8. 喂一个 `needs-input`（按 4）让气泡挂上 → 再手动点个动作 →
   **气泡应保持原样**（它是 agent 的信息，不受手动把玩影响）。

**2026-09-22 追加（ADR 039 / 040）**：

    探针一直用合成点击，而"隐藏后再显示是否还能收到真实鼠标按钮"只对键盘验证过。
    现在实测过了 —— 但你手点一次是最直接的确认）；
