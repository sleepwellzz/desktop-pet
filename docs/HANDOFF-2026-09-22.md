## 5. 环境事实（本轮新增两条）

- **PowerShell 读注册表**：`(Get-ItemProperty -Path "HKCU:\...\Run" -Name "<值名>").'<值名>'`
  —— 直接取属性。**不要用 `Get-ItemProperty` 的表格输出，长值会折行**，解析出来是残缺内容。
- **rcedit 是原生 exe**（`node_modules/rcedit/bin/rcedit.exe`）：含空格路径用
  `spawnSync(exe, args, { shell: false })`，走 shell 会被空格截断；
  写进版本资源的值**一律 ASCII**（中文读出来是乱码）。
- 原有：Bash shim 缺 head/tail/dirname；npm 可用；Edit 偶发"报告成功但文件没变"；
  路径含空格要用 `fileURLToPath`；跑 Electron 前删 `ELECTRON_RUN_AS_NODE`；
  `dist/`、`dist-win/` 已 gitignore。
