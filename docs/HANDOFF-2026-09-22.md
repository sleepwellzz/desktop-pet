## 2. 打包与分发（要发给别人时看这里）

**分发单位是「整个目录」，不是那个 exe。**

```
dist-win/desktop-pet/                  373 MB、232 个文件  ← 这一整个目录才是"软件"
dist-win/desktop-pet-win-x64.zip       153 MB             ← 发给别人的那**一个**文件
```

- 生成：`npm run make:portable`（只出目录）或 `npm run make:portable:zip`（顺带压 zip）。
- **`desktop-pet.exe` 不能单独发人** —— 它只是入口，启动时要在**同级目录**找
  `resources/`、`*.dll`、`*.pak`、`locales/`；只发一个 exe 出去，对方双击的症状是
  **毫无反应且没有任何报错**（这个症状本项目实测踩过）。详见 ADR 037。
- 实测过：把 zip 解压到全新目录能直接启动（窗口显示、精灵图就绪、零未捕获异常）。
- **进 zip 的文件名一律 ASCII** —— 非 ASCII 名会被 bsdtar 写坏（`说明.txt` 曾变成乱码，
  现为 `README.txt`）。同理：`.bat` 纯 ASCII、exe 版本资源的值 ASCII。

## 6. 环境事实（本轮新增两条）

- **PowerShell 读注册表**：`(Get-ItemProperty -Path "HKCU:\...\Run" -Name "<值名>").'<值名>'`
  —— 直接取属性。**不要用 `Get-ItemProperty` 的表格输出，长值会折行**，解析出来是残缺内容。
- **rcedit 是原生 exe**（`node_modules/rcedit/bin/rcedit.exe`）：含空格路径用
  `spawnSync(exe, args, { shell: false })`，走 shell 会被空格截断；
  写进版本资源的值**一律 ASCII**（中文读出来是乱码）。
- 原有：Bash shim 缺 head/tail/dirname；npm 可用；Edit 偶发"报告成功但文件没变"；
  路径含空格要用 `fileURLToPath`；跑 Electron 前删 `ELECTRON_RUN_AS_NODE`；
  `dist/`、`dist-win/` 已 gitignore。
